# Tailwind Example Page

## Overview
This singular web page containing an image gallery was styled using Tailwind CSS to demonstrate my proficiency with this CSS framework.<br>
A preview of what this project looks like when deployed can be viewed on Vercel at this link: https://tailwind-example-page.vercel.app/

## Tech Stack
- HTML5
- Tailwind CSS
